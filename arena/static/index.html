    THE IDEA BEHIND THE ARENA

    Don't trust the model.
    Constrain its effects.

    Prompt injection blurs the line between instructions and data. Spanguard tracks where text comes from and checks what the agent is allowed to do.

    Explore the architecture ↗
    01 / PROVENANCE

    Know where words come from.

    External content carries its origin and stays marked as untrusted. Random fences make boundary forgery harder.

    02 / AUTHORIZATION

    The model asks. The firewall decides.

    Tool calls are checked against permissions and untrusted influence before their effects can leave the agent.

    03 / EGRESS

    Check what leaves.

    Outbound text and tool arguments are inspected for registered secrets and unapproved destinations.

    A LAB, NOT A GUARANTEE

    This arena uses a deliberately gullible mock agent, not a live LLM. Ingress detection is best-effort; secret matching explores a bounded set of encodings. A contained attempt is evidence about that attempt, not proof against every attack.
